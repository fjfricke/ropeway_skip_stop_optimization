# Research archive

This directory preserves historical experiment controllers and documentation that
are no longer part of the current thesis workflow. They remain useful for
provenance and for interpreting old result packages, but they are not supported
entry points for new experiments.

Current runners live in `benchmarks/`, current contracts and plans in `docs/`,
and shared solver and validation code in `src/`. Git history remains the source
for exact earlier revisions. Moving a file here does not relabel or invalidate
any historical result.
